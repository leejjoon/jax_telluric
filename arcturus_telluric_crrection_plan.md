* arcturus nir spectra : "../differentiable_stellar_spectroscopy/data/atlases/arcturus/"

* arcturus model spectra : use payne zero (https://github.com/tingyuansen/payne-zero) with stellar parameters from literatures. 

* Use the current package to derive telluric model.

* Start with a single page (order?) from the nir spectra, with relatively well defined telluric absorption.

* One may need to fit the continuum simultaneously.

* Telluric model parameters for different page can be slightly different.
